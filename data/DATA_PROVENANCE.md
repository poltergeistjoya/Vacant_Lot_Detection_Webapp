# Data Provenance

Static geographic datasets used by the app. These are downloaded once and
committed — they change infrequently (NYC redraws CD boundaries roughly
once per decade).

## community_districts.geojson

- **Source**: NYC Open Data — "Community Districts"
- **URL**: https://data.cityofnewyork.us/City-Government/Community-Districts/jp9i-3b7y
- **Format**: GeoJSON (exported from Socrata)
- **CRS**: EPSG:4326 (WGS84)
- **Features**: 71 polygons — all five boroughs. Bronx CDs are BoroCD 201–212 plus parks (226–228).
- **Properties**: `BoroCD` (borough×100 + district number), `Shape_Leng`, `Shape_Area`
- **Downloaded**: 2026-09 (unchanged since 2024 redistricting)
- **Size**: ~3.6 MB

## bronx_boundary.geojson

- **Source**: US Census TIGER/Line — Bronx County boundary
- **CRS**: EPSG:4269 (NAD83)

## bronx_areawater.geojson

- **Source**: US Census TIGER/Line — Bronx County area water bodies
- **CRS**: EPSG:4269 (NAD83)
- **Used to**: subtract water from the county boundary to get land-only mask

## roads.geojson

- **Source**: US Census TIGER/Line — Bronx County roads
- **CRS**: EPSG:4269 (NAD83)
- **Used to**: burn road buffers out of vacant masks (8m buffer)

## athletic_surfaces.geojson

- **Source**: OpenStreetMap via Overpass API
- **Query**: `leisure=pitch` and `leisure=track` within Bronx bounding box
- **Sport types included**: baseball, softball, basketball, tennis, soccer, american_football, field_hockey, multi, running tracks
- **CRS**: EPSG:4326 (WGS84)
- **Generated by**: `scripts/fetch_athletic_surfaces.py` — run `cd scripts && uv run fetch_athletic_surfaces.py`
- **Used to**: source polygons for athletic surface analysis layer
- **License**: ODbL — (c) OpenStreetMap contributors

## athletic_surfaces_enriched.geojson

- **Source**: `athletic_surfaces.geojson` enriched with model prediction coverage
- **Generated by**: `scripts/prepare_athletic_surfaces.py` — run `cd scripts && uv run prepare_athletic_surfaces.py`
- **CRS**: EPSG:4326 (WGS84)
- **Properties**: original OSM tags + per-threshold coverage fractions (`t0000`–`t1000`) + `model_vacant` boolean
- **Used to**: frontend "Athletic Surfaces" map layer showing false positives

## ArcGIS Endpoints (MapPLUTO)

NYC Dept of City Planning publishes MapPLUTO (the merged PLUTO + tax lot boundary dataset) through ArcGIS Hub:

- **Query endpoint** (data download):
  `https://services5.arcgis.com/GfwWNkhOj9bNBqoJ/arcgis/rest/services/MAPPLUTO/FeatureServer/0/query`
  Used to download parcel geometries and attributes. Supports `where`, `outFields`, pagination via `resultOffset`/`resultRecordCount`, and GeoJSON output (`f=geojson`).

- **Service metadata endpoint** (version info):
  `https://services5.arcgis.com/GfwWNkhOj9bNBqoJ/arcgis/rest/services/MAPPLUTO/FeatureServer/0`
  Returns service info including `editingInfo.dataLastEditDate` — the timestamp of the last data update, used to tag the `pluto_version` in the output.

## parcels.geojson

- **Source**: NYC MapPLUTO via ArcGIS FeatureServer (see endpoints above)
  - Filter: `BoroCode=2` (Bronx only), paginated at 2000 records
- **Generated by**: `scripts/prepare_parcels.py` — run `cd scripts && uv run prepare_parcels.py`
- **CRS**: EPSG:4326 (WGS84)
- **Inclusion criterion**: a parcel is included if MapPLUTO records it as vacant (LandUse=11) OR the model predicts ≥20% pixel coverage at any confidence threshold >0
- **Properties**:
  - `bbl`, `address`, `owner_name`, `owner_type`, `lot_area`, `zoning`, `land_use` — from MapPLUTO
  - `pluto_vacant` — boolean, true if MapPLUTO LandUse=11
  - `t0000`..`t1000` — pixel coverage fraction (0–1) at each confidence threshold; the fraction of the parcel's rasterized area where model probability exceeds that threshold
- **Metadata** (top-level `metadata` object in the GeoJSON):
  - `pluto_version` — date of last MapPLUTO data update
  - `counts_by_threshold` — number of visible parcels at each threshold (pluto-vacant OR coverage ≥20%)
  - `coverage_threshold` — the 20% pixel coverage criterion used
- **Frontend behavior**: vacancy category (both/model_only/pluto_only) and parcel visibility are computed dynamically from `pluto_vacant` + the coverage value at the slider's current threshold
- **Cache**: raw API download cached to `data/cache/bronx_mappluto.geojson` (gitignored)
- **Size**: ~10–20 MB depending on threshold range and Bronx vacancy counts
